Hellenic Technologies manages Google Ads across Search, Display, Shopping, and YouTube for 100+ clients globally. This guide walks through the standard processes for account setup, campaign management, weekly optimisation routines, and reporting — ensuring every Paid Media Specialist and Account Manager follows a consistent, high-quality delivery standard.

## Campaign Types We Handle

We run the following Google Ads campaign types across the client portfolio:

- **Search** — text ads triggered by keyword queries; core for lead gen and direct response
- **Performance Max (PMax)** — goal-based campaigns that run across all Google inventory
- **Display** — image and responsive ads across the Google Display Network
- **Shopping** — product-feed-driven ads for eCommerce clients
- **YouTube** — video ads (skippable, non-skippable, bumper, in-feed)
- **Demand Gen** — visual, discovery-style campaigns across YouTube, Gmail, and Discover

## New Account Setup

Follow these steps every time you onboard a new Google Ads client. Do not skip steps — each one is a dependency for accurate tracking and performance.

<Steps>
  <Step title="Create Google Ads Account Under HT MCC">
    Set up the new client account inside the Hellenic Technologies Manager Account (MCC). Never create standalone accounts outside the MCC — this ensures billing control, cross-account reporting, and central access management. Name the account using the format: `ClientName | Country | MM/YYYY`.
  </Step>
  <Step title="Link Google Analytics 4 Property">
    Link the client's GA4 property to the new Google Ads account via the **Linked Accounts** section in Google Ads settings. Confirm the link is active and that auto-tagging is enabled. If the client does not yet have GA4, raise this immediately with the Analytics team.
  </Step>
  <Step title="Set Up Conversion Tracking">
    Configure all relevant conversion actions: website conversions (form fills, purchases, sign-ups), phone call conversions, and any offline imports. Use Google Tag Manager for tag deployment — coordinate with the Web Analytics team if GTM is not yet installed. Verify each conversion action is firing correctly before campaign launch.
  </Step>
  <Step title="Build Campaign Structure Aligned With Client Objectives">
    Map out the campaign and ad group structure before creating anything in the platform. Align the structure with the client's goals (e.g., brand vs. generic keywords in separate campaigns, products grouped by category for Shopping). Document the structure in the client's account folder on the shared drive.
  </Step>
  <Step title="Set Budgets and Bidding Strategies">
    Apply daily budgets as agreed in the client's signed proposal. Select the appropriate bidding strategy: Target CPA, Target ROAS, Maximise Conversions, or Maximise Conversion Value depending on the campaign objective and data maturity. Use Manual CPC only during the initial data-gathering phase if conversion history is insufficient for Smart Bidding.
  </Step>
  <Step title="Create Ad Copy and Extensions">
    Write Responsive Search Ads (RSAs) with a minimum of 8–10 headlines and 4 descriptions, covering brand USPs, CTAs, and keyword inclusion. Set up all relevant ad extensions: sitelinks, callouts, structured snippets, call extensions, location extensions (where applicable). Get ad copy signed off by the Account Manager before enabling.
  </Step>
  <Step title="Launch and Monitor First 48 Hours Closely">
    Once live, check the account twice daily for the first 48 hours. Confirm ads are serving, budgets are pacing correctly, and conversion tracking is recording. Flag any anomalies to the Account Manager immediately. Document your launch check in the client's Slack channel.
  </Step>
</Steps>

## Weekly Optimisation Routine

Carry out the following checks every week for all active Google Ads accounts:

- **Search terms report** — identify irrelevant queries and add them as negative keywords
- **Negative keyword list** — update the shared negative keyword list and apply to relevant campaigns
- **Bid adjustments** — review device, location, and audience bid modifiers; adjust based on performance data
- **Ad performance** — pause underperforming ads (CTR below threshold, low conversion rate); test new ad variants
- **Quality Score** — monitor QS at keyword level; address low scores with landing page improvements or ad relevance fixes

Log all optimisation actions in the client's weekly optimisation notes doc in the shared drive.

<Note>
  Any budget change greater than **20% of the current daily budget** requires explicit client approval before implementation. Send the request via email or the agreed client communication channel and wait for written confirmation. Document the approval in the client folder. This applies to both increases and decreases.
</Note>

## Reporting

Pull performance data from both **Google Ads** and **GA4** for all monthly reports. The monthly report template is located in the shared drive at `/Templates/Reporting/Digital Marketing/Google Ads Monthly Report.pptx`.

Reports must include at minimum: impressions, clicks, CTR, average CPC, conversions, cost per conversion, and ROAS (where applicable). Add a brief written commentary on performance trends and planned optimisations for the next period.

For weekly performance campaign reports, use the condensed weekly template in the same folder.

## Common Issues

<Accordion title="Campaign not spending its budget">
  This is usually caused by one or more of the following:

  - **Bid strategy too conservative** — if using Target CPA or Target ROAS, the targets may be too tight for the algorithm to spend. Try relaxing targets slightly or switch to Maximise Conversions temporarily.
  - **Targeting too narrow** — review geographic targeting, audience restrictions, and keyword match types. Broadening match types or expanding locations can unlock spend.
  - **Low Quality Score** — a poor QS means Google won't enter your ads into auctions competitively. Improve ad relevance, expected CTR, and landing page experience.
  - **Ad disapprovals** — check the Ads & Extensions tab for any disapproved ads. Resolve policy issues promptly.
</Accordion>

<Accordion title="High cost per lead (CPL)">
  High CPL typically points to one of three areas:

  - **Keyword targeting** — review whether keywords are too broad or attracting irrelevant traffic. Tighten match types or refine your negative keyword list.
  - **Landing page quality** — a poor post-click experience kills conversion rate. Check landing page load speed, message match with the ad, and clarity of the CTA. Escalate to the Web Dev team if structural changes are needed.
  - **Audience targeting** — if running Display or PMax, ensure audience signals are well-defined. Exclude audiences that are consistently non-converting.
</Accordion>

<Accordion title="Conversion tracking not firing">
  Before raising a bug, work through this checklist:

  1. Confirm the GTM container is published and the tag is set to the correct trigger.
  2. Use GTM Preview mode and/or the Google Tag Assistant Chrome extension to verify the tag fires on the intended action.
  3. Check that the conversion action in Google Ads is set to "Every conversion" or "One conversion" as appropriate.
  4. Confirm auto-tagging is enabled on the Google Ads account.
  5. If the issue persists, raise a task for the Web Analytics team with a screen recording showing the GTM Preview output.
</Accordion>
