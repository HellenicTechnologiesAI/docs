<Warning>
  **No Cloudflare / no same-origin:** leave Generate **Same Origin Path empty**. Do not copy HT `/metrics`. Hellenic.com passed Safari ITP because its loader **is** same-origin (`j.src = "/metrics/…"`), not because of a second Cookie Keeper file. Filling `/metrics` without a Worker **breaks** the loader.

  Cookie Keeper is **after** the first loader and tags work. First Generate: Cookie Keeper **off**. After named publish \+ QA: Generate **with** Cookie Keeper, user identifier **Stape User ID**, and tell web-dev to **replace** the previous IIFE (do not add a second snippet). Do not pick the Cookie identifier unless a compliant server-set master cookie already exists.

  Worked example: [Golden Gastro](/kb/web-analytics/customers/golden-gastro).
</Warning>

Use this when the customer **already has** Stape \+ web GTM \+ sGTM. First reply must be an audit, then a patch spec. No GTM edits until you approve.
