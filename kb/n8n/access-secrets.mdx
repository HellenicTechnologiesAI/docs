## Cursor Cloud environment (required for SSH)

Launch agents on the personal Cloud environment **hellenictechnologies/omniai**:

[https://cursor.com/dashboard/cloud-agents/environments/e/9847f7d0-a526-11f1-a7d1-d6b4613131ce](https://cursor.com/dashboard/cloud-agents/environments/e/9847f7d0-a526-11f1-a7d1-d6b4613131ce)

That snapshot has `~/.ssh/omniai_do`. Teammates on their own Cursor account do **not** inherit this key. They need the same public key installed on the boxes and their own personal secret `OMNIAI_SSH_PRIVATE_KEY`.

Confirm live DigitalOcean:

`ssh -i ~/.ssh/omniai_do -o BatchMode=yes -o ConnectTimeout=8 root@167.172.39.204 hostname`

Expected: `n8n-ams3`.

AWS Ireland rollback is **stopped**. SSH to `34.249.195.203` times out until someone starts `i-02b985625556f7bd6`. Do not start it while DigitalOcean n8n is running.

## SSH

| Path / command | What |
| --- | --- |
| `~/.ssh/omniai_do` | Agent private key (DigitalOcean name `omniai-cursor-agent`, ID `58992798`) |
| `root@167.172.39.204` | Live DigitalOcean `n8n-ams3` |
| `ubuntu@34.249.195.203` | AWS Ireland rollback |
| AWS console key name | `aws_n8n_ireland` — we do not have that private key. |

Public key comment: `omniai-cursor-agent`. Install only the **public** key on extra boxes. Never commit the private key.

## Env files on the boxes (values stay there)

| File | Key names only |
| --- | --- |
| `/opt/n8n/.env` | `DOMAIN`, `N8N_ENCRYPTION_KEY`, `N8N_EMAIL_ADDRESS`, `N8N_PASSWORD`, `NODE_ENV`, `GENERIC_TIMEZONE`, `TRUST_PROXY_SSL_HEADERS`, `NODE_FUNCTION_ALLOW_EXTERNAL`, `DB_TYPE`, `DB_POSTGRESDB_*`, `REDIS_*`, queue keys, `SUPABASE_SERVICE_ROLE_KEY` |
| `/opt/n8n/parts-api.env` | `AILENS_GOOGLE_API_KEY`, `AILENS_GOOGLE_API_KEY_PERSONAL`, `AILENS_OPENAI_API_KEY`, `AILENS_SUPABASE_URL`, `AILENS_SUPABASE_KEY` |
| `/opt/ai-lens/.env` | same AI Lens names as `parts-api.env` |

`N8N_ENCRYPTION_KEY` must stay the same or saved credentials in n8n will not decrypt.
