## How to look up a client

1. Search this page or the KB for the client name (also try the GTM ID).
2. Use **Web GTM**, **GA4 ID**, **Meta Ads**, and **Google Ads** from the matching row.
3. If the cell is blank, open the [live sheet](https://docs.google.com/spreadsheets/d/1ZDcH_Zp141uR516Fb3xfxoaOS4iwNgL47NXxBVhG9os/edit) or list accounts via [platform access](/kb/web-analytics/cursor-ga4-meta-access).
4. If you add or correct a client, update the sheet first, then this page.

**GA4 ID** in the sheet is a numeric property ID, not a `G-` measurement ID. **Meta Ads** is the ad-account number (no `act_` prefix). **Google Ads** is the CID with dashes.

## Shared sGTM

Four rows fill **sGTM ID** in the sheet: Avance, Camelot GR, GrecoStrom, and Gatsoulis. That value is the public ID of the HT multi-tenant server container (same one as the [SST playbook](/kb/web-analytics/server-side-tracking)). Add a domain on that container. Do **not** create a second Stape or sGTM container. Other rows leave sGTM blank in the sheet.
