n8n is Hellenic Technologies workflow host. Public URL is `https://n8n.hellenictechnologies.com`. Same IP also answers the typo hostname `n88n.hellenictechnologies.com`.

The editor, webhooks, **parts-api**, and **crawl-proxy** share one box and one Caddy vhost. They are **not** OmniAI Chatwoot. Do not install this stack on `omniai-prod-ams3` or `omniai-staging-ams3`.

## Hard rules

1. Do not put n8n, parts-api, or crawl-proxy on the OmniAI Chatwoot droplets.
2. Do not point this stack at OmniAI managed Postgres or Valkey. n8n keeps its own Docker Postgres 16 and Redis 7.
3. Do not orange-cloud `n8n` or `n88n`. Grey-cloud only. Caddy on the box owns HTTPS.
4. Do not pull `n8nio/n8n:latest` on this host. Image is pinned to **`n8nio/n8n:2.14.2`**.
5. Do not start n8n on the AWS box while DigitalOcean n8n is running. Same crons would fire twice.
6. Do not mention DigitalOcean or this cutover to outside devops unless they already operate this box.
7. Do not commit `/opt/n8n/.env`, `/opt/n8n/parts-api.env`, `/opt/ai-lens/.env`, `N8N_ENCRYPTION_KEY`, or API keys.
8. Do not print those values in chat. Names of keys are fine. Values are not.
9. Keep `N8N_ENCRYPTION_KEY` unchanged or saved credentials will not decrypt.
