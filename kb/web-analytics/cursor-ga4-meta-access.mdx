## How agents authenticate

Secrets are injected as env vars on Cloud Agents (`All Repositories`, Runtime Secret). Read `process.env` / `$NAME`. Names are case-sensitive.

| Surface | Identity | Secret names (use these) | Call style |
| --- | --- | --- | --- |
| **GA4 / GTM / Sheets / GSC** | `digital@hellenictechnologies.com` | `GOOGLE_OAUTH_CLIENT_ID` `GOOGLE_OAUTH_CLIENT_SECRET` `GOOGLE_OAUTH_REFRESH_TOKEN` | REST. Refresh, then Bearer. |
| **Google Ads** | same human, MCC | `GOOGLE_ADS_CLIENT_ID` `GOOGLE_ADS_CLIENT_SECRET` `GOOGLE_ADS_REFRESH_TOKEN` `Google_Ads_developer_token` `GOOGLE_ADS_MCC_ID` | **`google-ads-api` gRPC only.** Never REST `googleads.googleapis.com` (HTML 404). |
| **DV360** | Partner `1606967182` | `DV360_CLIENT_ID` `DV360_CLIENT_SECRET` `DV360_REFRESH_TOKEN` `DV360_PARTNER_ID` | REST `displayvideo.googleapis.com`. |
| **Meta** | `HT-SysAdmin` | Prefer `META_ADS_ACCESS_TOKEN`. Fallback `META_ADS_TOKEN` then `META_ACCESS_TOKEN`. | Graph REST. |

Aliases: `GOOGLE_ADS_MCC_ID` is the login-customer-id (digits, no dashes). `Google_Ads_developer_token` is the Ads developer token (that exact casing). `GOOGLE_SERVICE_ACCOUNT_JSON` is Drive/KB only — not this stack.

<Note>
  If `GOOGLE_OAUTH_*` is missing, GA4 Admin and GTM APIs will fail even when Ads/Meta work. Add those three secrets. Do not fall back to inviting the service account.
</Note>

## Refresh a Google access token

Do this in-process. Do not log the response body.

```bash
curl -sS -X POST https://oauth2.googleapis.com/token \
  -d "client_id=$GOOGLE_OAUTH_CLIENT_ID" \
  -d "client_secret=$GOOGLE_OAUTH_CLIENT_SECRET" \
  -d "refresh_token=$GOOGLE_OAUTH_REFRESH_TOKEN" \
  -d "grant_type=refresh_token"
```

Ads and DV360 use the same token URL with their own `CLIENT_ID` / `CLIENT_SECRET` / `REFRESH_TOKEN`.

Then:

- GA4 list: `GET https://analyticsadmin.googleapis.com/v1beta/accountSummaries?pageSize=200`
- GA4 report: `POST https://analyticsdata.googleapis.com/v1beta/properties/{id}:runReport`
- GTM list: `GET https://tagmanager.googleapis.com/tagmanager/v2/accounts`
- Meta list: `GET https://graph.facebook.com/v19.0/me/adaccounts?fields=id,name,currency` with `META_ADS_ACCESS_TOKEN`
- Ads children: `google-ads-api` `customer_client` on `GOOGLE_ADS_MCC_ID`. Header login-customer-id = that MCC.
- DV360: `GET https://displayvideo.googleapis.com/v4/advertisers?partnerId=$DV360_PARTNER_ID`

Expected sizes when healthy: GA4 ~84 accounts / ~192 properties; GTM ~210 accounts; Ads ~124 MCC children; Meta ~57 ad accounts.

## What Cursor must not do

- Invite `*.iam.gserviceaccount.com`
- Print or commit tokens
- Call `googleads.googleapis.com` over REST
- Create a Meta pixel because Graph 404s
- Reuse HT pixel / HT GA4 / HT web GTM on another hostname
