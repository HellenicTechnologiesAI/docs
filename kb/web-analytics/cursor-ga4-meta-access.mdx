## Agent rules

1. Need GA4 data or Admin writes (key events, audiences)? Refresh the **digital@** token, then `accountSummaries` / `properties/{id}`. Prefer the 192-property list over guesses.
2. Need GTM reads/writes? Same token. `GET …/tagmanager/v2/accounts` then `…/accounts/{id}/containers`.
3. Need Google Ads? `google-ads-api` \+ MCC `3568564840` as `login-customer-id`. Never raw REST to `googleads.googleapis.com`.
4. Need Meta? `HT-SysAdmin` token. If the customer ad account or pixel is missing from the 57, stop and report **not writable**. Partner-share that BM into HT, then assign the asset to `HT-SysAdmin`.
5. A previous agent that said it only had HT `properties/394561578` was using the **service account**, not this OAuth. Ignore that report.

## When a _new_ client is missing

Invite the **human** `digital@hellenictechnologies.com`, not a service account.

| Product | What to add |
| --- | --- |
| GA4 | Account access management → add `digital@hellenictechnologies.com` as Editor or Administrator. The UI accepts this email. |
| GTM | Account User Management → add `digital@` as Account Admin. |
| Google Ads | Link the advertiser under MCC `3568564840`. `digital@` already sits on the MCC. |
| Meta | Client BM → Partners → HT Business ID → share ad account \+ dataset → assign to `HT-SysAdmin`. |

One add per **account / MCC / Business**. Not per property, container, or pixel.
