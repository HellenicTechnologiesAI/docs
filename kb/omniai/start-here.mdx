## Hard rules

1. After a file copy into a running container, **restart** Rails and Sidekiq. Do not recreate them. Recreate boots the old image and drops copied files.
2. Do not overwrite `/opt/omniai/.env` or the live compose line `image: chatwoot:production`. The repo compose may say `omniai:development`.
3. Do not compile a full image on live for Ruby, ERB, `en.yml`, Super Admin views, or a migration-only change.
4. Do not stop the live site just to compile. Native gem compiles run out of memory on the 8 GB box if Rails and Sidekiq stay up.
5. Do not point staging at the live managed database or Valkey.
6. Do not change Cloudflare `app` or `hc` when working on staging.
7. Do not reorder `config/features.yml`. Duplicate `linear_integration` stays. See [Super Admin flags](/kb/omniai/super-admin-features).
8. Do not mention DigitalOcean or the cutover to outside devops unless they already operate this box.
9. Do not commit the SSH key, the live env file, Spaces keys, `DIGITALOCEAN_ACCESS_TOKEN`, `CLOUDFLARE_API_TOKEN`, or mailer passwords.
10. Do not leave product pull requests open. Merge finished work into `omniai`.
11. Do not assume GitHub Actions updated live.
12. Do not upgrade to Chatwoot 4.17 unless a human accepts a full rewrite of the custom fork.

## First 10 minutes on a new agent

<Steps>
  <Step title="Use the Cloud environment that already has the SSH key">
    Launch on the personal Cursor Cloud environment **hellenictechnologies/omniai**: [environment e/9847f7d0-a526-11f1-a7d1-d6b4613131ce](https://cursor.com/dashboard/cloud-agents/environments/e/9847f7d0-a526-11f1-a7d1-d6b4613131ce).

    Confirm: `test -f ~/.ssh/omniai_do && ssh -i ~/.ssh/omniai_do -o BatchMode=yes -o ConnectTimeout=8 root@188.166.84.105 hostname`

    Expected print: `omniai-prod-ams3`. Details: [Access and secrets](/kb/omniai/access-secrets).
  </Step>
  <Step title="Read AGENTS.md">
    Same deploy rules live in `AGENTS.md` (`CLAUDE.md` is a symlink). This KB is the expanded runbook.
  </Step>
  <Step title="Decide hotfix vs image rebuild">
    Ruby, ERB, `en.yml`, Super Admin, one migration → hotfix. Gemfile, native gems, Dockerfile, compiled Vue → rebuild on staging, then promote. [Ship fixes](/kb/omniai/deploy-hotfixes).
  </Step>
  <Step title="Merge to omniai, then patch the Droplet">
    Code on GitHub is not live. After merge, copy files into `/opt/omniai` and into the running containers.
  </Step>
</Steps>
