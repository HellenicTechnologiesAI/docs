## Hard locks

- Do **not** create a new Stape or sGTM container.
- Stape: existing **Multi-tenant** container (same identifier as the [SST playbook](/kb/web-analytics/server-side-tracking)), EU Center (Germany).
- sGTM: same shared server container. Fork **live**, never a stale Default workspace.
- Web GTM: keep `GTM-N7G3WK`. No second web container.
- Custom domain: `sgtm.grecostrom.gr` — DNS-only (not proxied).
- Same-origin `/metrics` **only** if Cloudflare zone access is confirmed. Filling `/metrics` without a Worker breaks the loader.
- Cookie Keeper is a **second** Generate after the first loader + tags work. User identifier = Stape User ID.
- Do **not** copy HT or Golden Gastro IDs onto this hostname.
- Keep TikTok. Do not delete it.
- One Ads e-shop primary: **Purchase**. Papafi store-visit stays a separate goal.
