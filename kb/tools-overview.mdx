Hellenic Technologies runs on a carefully selected stack of tools and platforms that spans AI, digital marketing, web development, data analytics, and internal operations. Knowing which tool to use — and how to access it — saves time and avoids duplicated effort. This page gives every team member a consolidated reference for the software we use day-to-day, organised by function. If you need access to a tool not currently in your account, see the note at the bottom of this page.

    ## Underlying AI Model Providers

    hellenicAI products are powered by leading foundation model providers. Familiarity with these models helps you set appropriate client expectations and choose the right model for each use case.

    | Provider | Models | Typical Use Case |
    |----------|--------|-----------------|
    | Anthropic | Claude (Haiku, Sonnet, Opus) | Long-context reasoning, document analysis, conversational AI |
    | OpenAI | GPT-4o, GPT-4o mini | General-purpose chat, function calling, multimodal tasks |
    | Google | Gemini 1.5 Pro / Flash | Multimodal inputs, Google ecosystem integrations |
    | Mistral AI | Mistral Large, Mistral Small | Cost-efficient European-hosted inference, GDPR-friendly |

    <Note>
      Model selection for client deployments is determined by the AI Division. Do not change the underlying model of a live client assistant without approval from the AI Product Lead.
    </Note>
