- Stape: existing **Multi-tenant** container (same identifier as the [SST playbook](/kb/web-analytics/server-side-tracking)), EU Center (Germany).
- sGTM: same shared server container as the playbook (account `6202173174`, container `169217628`). Live **v220**. Fork **live**, never workspace 208.
- **Never publish Default Workspace 208** (stale, 79 tags).
- Web GTM: keep `GTM-N8ZFXBTK` (account `6357803150`, container `253795963`). No second web container. Live **v16**.

- Same-origin: **on**. Path is `/metrics` only. Worker `gg-sgtm-metrics` already exists. Do **not** add a second Worker. Do **not** invent another path.
- Do **not** enable Own CDN on `sgtm.goldengastro.de` while same-origin is on. Own CDN \+ same-origin together is wrong.
- Do **not** orange-cloud `sgtm.goldengastro.de`.
- `server_container_url` on this hostname = `location.origin + '/metrics'`.
- Custom Loader filename is shared on this multi-tenant container; **query selects the site**. Bare file without query = 404.
- Do **not** deactivate GTM4WP. Container \+ plugin tags off. Woo ecommerce toggle can stay off — GTM builder fills events.
- Do **not** unpause web `GG | Google tag Ads` / `GG | Ads *` awct.
- Do **not** start GTM “Measure purchases in Google Ads” wizard.
- Do **not** use HT env `META_PIXEL_ID` / `META_CAPI_ACCESS_TOKEN` (those are the HT website).
- Do **not** generate Cookie Keeper again. Do **not** replace the live snippet.
