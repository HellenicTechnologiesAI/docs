## Hard rules

1. Always land on **`main`**. Never open or leave a pull request.
2. Production deploys from Dashboards `main` automatically (Vercel ht-reporting). Confirm the deploy is READY before telling a human it is live.
3. Do not invent dashboard UI. Vendor the shell wholesale, then wire tenancy and ClickHouse.
4. Do not restore `/app` or the old scorecard chrome. `/app` and `/app/*` redirect to `/` (`/app/web` → `/ga4`).
5. Session allow-list is tenancy. Ignore browser `clientId` for who the tenant is. APIs 403 any client id not in the session list.
6. Do not copy demo shell accounts (`aegean-retail`, `ionian-travel`, `attica-fashion`) into live tenancy.
7. No new ingest unless asked. TikTok and DV360 stay on the empty panel until ingest exists.
8. Do not restyle `/admin` as a one-off. Admin lives in the shell design system; re-vendor from the shell SHA.
9. Do not commit secrets. Token names belong in [Access](/kb/hellenicai-bi/access). Values stay in Vercel / Cloud Agent secrets.

## Compare in the header

Not previous calendar month.

| Option | Meaning |
| --- | --- |
| vs previous N days (dates) | Equal-length window ending the day **before** the selected range starts. Last 30 days 22 Aug–20 Sept → **23 Jul–21 Aug**. |
| vs same period last year | Same from/to, one year back. |
| No comparison | Hide deltas. |

Math is `compareRange()` in `lib/bi/dates.ts`. Do not change the meaning without updating this page and the dropdown copy.
