## Cursor Cloud environment (required for SSH)

Launch agents on the personal Cloud environment **hellenictechnologies/omniai**:

[https://cursor.com/dashboard/cloud-agents/environments/e/9847f7d0-a526-11f1-a7d1-d6b4613131ce](https://cursor.com/dashboard/cloud-agents/environments/e/9847f7d0-a526-11f1-a7d1-d6b4613131ce)

That snapshot already has `~/.ssh/omniai_do`. Confirm:

`test -f ~/.ssh/omniai_do && ssh -i ~/.ssh/omniai_do -o BatchMode=yes -o ConnectTimeout=8 root@188.166.84.105 hostname`

Expected: `omniai-prod-ams3`.

A new or repo-only environment will not have the key. Copy `omniai_do` onto that VM (do not commit it), then take an environment snapshot so later agents inherit it.

## SSH and agent extras (not in Git)

| Path | What |
| --- | --- |
| `~/.ssh/omniai_do` | Droplet SSH private key |
| `~/.config/omniai-do/ids.env` | IDs and IPs (Droplet, VPC, project, Postgres ID, Valkey ID, Spaces bucket name) |
| `~/.config/omniai-do/pg-conn.json` | Postgres connection helper |
| `~/.config/omniai-do/spaces.env` | Spaces key names / files |
| `/opt/omniai/.env` on live | The real app secrets |
| `/opt/omniai/.env.bak-resend` | Backup from the Resend switch |

`ids.env` key names: `SSH_KEY_ID`, `VPC_ID`, `PROJECT`, `PG_ID`, `VK_ID`, `SPACES_BUCKET`, `DROPLET_IP`, `DROPLET_ID`, `DROPLET_PRIVATE`, `STAGING_DROPLET_IP`, `STAGING_DROPLET_ID`, `STAGING_DROPLET_PRIVATE`.
