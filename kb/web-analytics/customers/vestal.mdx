## GDPR

iubenda stays in the web GTM tag (site `4402076`), not a copy of the Hellenic head banner. Accept and reject are both shown. Purpose toggles are on. Consent is not granted by continued browsing. The floating preferences button stays so people can change their mind.

Before accept: ads and analytics storage are denied. GA4 tags wait for analytics storage. Meta, Data Tags, and the conversion linker wait for ad storage. Marketing cookies are not written by those tags before purpose 5.

Server Meta tags on the shared container still have ad storage optional, because requiring it would stop other tenants that do not send consent. Vestal only sends those hits after ads consent.

A theme copy of the pixel or the banner would bypass this. That removal is the web-dev ticket.
