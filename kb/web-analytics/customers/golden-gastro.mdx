## Why this is not Hellenic.com

|  | hellenictechnologies.com | goldengastro.de |
| --- | --- | --- |
| Stape | Same **Multi-tenant** container | Same container — **add a domain** |
| sGTM | Shared HT server container | Same — hostname-scope only |
| Web GTM | `GTM-TRPS26L` | **`GTM-N8ZFXBTK` only** |
| Loader | `/metrics/…` **same-origin** (Cloudflare Worker) | `https://sgtm.goldengastro.de/…` **no same-origin** |
| ITP | Passed because of `/metrics`, not a second Cookie Keeper file | Needs **Cookie Keeper Generate** (Stape User ID), then **replace** the first loader |
| iubenda | HT site `3941073` | GG site **`4547427`** |
| GA4 | `G-GYMSRM45JV` (do not use) | **`G-LNPZX5HKQF`** |

HT ITP passed with “only Custom Loader” because that loader **is** same-origin (`j.src = "/metrics/dw0ie….js?"`). Golden Gastro has **no Cloudflare zone access**. **Do not type `/metrics` in Same Origin Path** — Stape will rewrite the loader and the site will break.

- Same-origin: **off**. No Worker, no `/metrics`, no Google tag gateway.
- `server_container_url` = `https://sgtm.goldengastro.de`.
- Custom Loader filename is shared on this multi-tenant container; **query selects the site**. Bare file without query = 404.
- Do **not** deactivate GTM4WP. Container \+ plugin tags off. Woo ecommerce toggle can stay off — GTM builder fills events.
- Do **not** unpause web `GG | Google tag Ads` / `GG | Ads *` awct.
- Do **not** start GTM “Measure purchases in Google Ads” wizard.
- Do **not** use HT env `META_PIXEL_ID` / `META_CAPI_ACCESS_TOKEN` (those are the HT website).
